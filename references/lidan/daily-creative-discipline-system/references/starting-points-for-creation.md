## Sources of Joke Ideas

### Insight (洞察)
- A moment of resonance ("I thought so too")
- Can be simple or subtle
- Examples: 'Involution', Jonathan Lee's lyrics

### Negative Emotions
- Look for: Hard, Weird, Scary, Stupid
- If something triggers these, it implies a logical problem
- Unpack these problems for humor

### Thematic Necessity
- Routines need a theme for传播 and resonance
- Beyond just being funny - must have thematic depth

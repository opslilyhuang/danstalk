## The Evolution Process (The Gap)

### Beginner Phase (Subtraction Process)
- Brain (100 points) → Script (70 points) → Stage (50 points)
- You cannot fully realize your imagination
- The performance is a reduction of the script

### Advanced Phase
- Over time, the gap shrinks
- Brain (70-80 points) → Stage (90 points)
- You become freer
- Generate unexpected improvisations that exceed the original idea

### Accepting the Initial Gap
- Requires acceptance that early performances will not match imagination
- The verbatim script provides the bridge between vision and execution

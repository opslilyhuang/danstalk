## 二、建议优化项（体验与一致性）

### 1. 视觉与动效
- **选题卡片**：文档要求「3D 翻转」— 当前为普通卡片，可做 CSS 3D 翻转或更明显的翻牌动效。
- **投信**：文档要求「信封飞入邮筒」— 当前为简单「信飞向诞总中…」+ emoji，可加 Lottie 或手写 SVG 信封飞行动画。
- **加载态**：统一为「诞总正在喝酒…」+ 酒液/酒杯晃动动画，替代任何 spinner。
- **首页头像**：用真实像素风头像图（或明确占位图）替代 emoji。

### 2. 电台体验
- **20% 立即回复**：当前为 100% 立即（演示用），可改为 20% 立即 + 80% 进入「信已投入，等待诞总拆阅…」并支持「花毒硬币插队」。
- **拆信仪式感**：回复前增加「收音机亮起 / 蜡封撕开 / 信纸展开」的短动画或分步展示。
- **波形图**：文档有「波形图随语音跳动」— 当前无语音，可先做随文字或模拟波形，为后续 TTS 预留。

### 3. 训练营体验
- **段位与进度**：展示「素人→开放麦老炮→专场演员→行业毒瘤」段位 + 进度环（如每局 +N 经验，满格升段）。
- **观众反应**：文档有「掌声/嘘声」— 当前仅掌声；可根据点评分数或随机加入嘘声/冷场，并接「救场现挂」彩蛋。
- **心流/难度**：根据历史表现或本局点评结果，下一局话题难度/角度略有变化（如更刁钻角度解锁）。

### 4. 文案与人格
- 全局文案再过一遍，确保符合 prompts 里的李诞语气（短句、留白、口头禅）。
- 错误/网络失败时的兜底文案统一成「诞总风」（如「害，信号不好…」已有一处，可推广）。

## 三、建议深度实现功能（玩法与系统）

### A. 毒硬币消耗（双模式联动 1）

| 功能 | 说明 | 建议 |
|------|------|------|
| **电台插队** | 投信后若未中 20%，可花 X 毒硬币「插队」立即获得回复 | 高优先级，直接让硬币有用 |
| **解锁高级话题** | 部分话题需消耗毒硬币才能选（如「相亲现场实录」需 5 币） | 中优先级，增加训练营目标感 |

### B. 背包与收藏（双模式联动 2）

| 功能 | 说明 | 建议 |
|------|------|------|
| **金句收藏** | 电台回复中可选中一句「收藏到背包」，支持从回复页一键收藏 | 中优先级 |
| **背包页** | 统一入口查看：收藏的金句、写过的段子（可只存最近 N 条）、获得的徽章 | 中优先级 |
| **金句→训练营** | 背包中的金句可在写段子时「插入为素材」或作为灵感参考 | 低优先级，可 V2 |

### C. 段位与徽章（训练营深度）

| 功能 | 说明 | 建议 |
|------|------|------|
| **段位进度条** | 每局 +经验，满格升段（素人→开放麦老炮→专场演员→行业毒瘤），在 TopBar 或训练营内展示 | 中优先级 |
| **徽章** | 达成条件解锁（如「连写 5 局」「第一次被夸有饭吃了」「冷场救场成功」），展示在背包/个人 | 低优先级 |
| **冷场与救场** | 演出阶段随机或按「段子长度/关键词」出现冷场→触发「救场现挂」小玩法，不扣分且解锁彩蛋 | 低优先级，增加趣味 |

### D. 电台深度

| 功能 | 说明 | 建议 |
|------|------|------|
| **往期列表** | 已回复的信列表（ArchiveShelf），可点开重看回复 | 中优先级 |
| **信池状态** | 未中 20% 时展示「信池中有 N 封信在排队」，增加仪式感 | 低优先级 |
| **语音朗读** | Phase 2：TTS 读回复（Web Speech API / ElevenLabs），配合波形图 | 低优先级 |

### E. 全局与基础设施

| 功能 | 说明 | 建议 |
|------|------|------|
| **设置页** | 语音开关、关于、清除本地数据等 | 低优先级 |
| **PWA** | 离线可写信、可看已缓存内容 | 低优先级 |
| **音效** | 掌声/嘘声/投信/拆信等音效（文档有清单） | 中优先级，对氛围帮助大 |

## 四、推荐实现顺序（供你勾选）

1. **毒硬币插队**（电台花币立即回复）— 让货币有明确用途。  
2. **20% 立即回复**（其余进等待）+ 插队入口 — 符合文档的斯金纳箱设计。  
3. **段位进度条**（训练营内 + 简单经验规则）— 提升训练营目标感。  
4. **金句收藏 + 背包页**（只做展示）— 打通「收藏」与统一入口。  
5. **往期电台列表**（已回复信可重看）— 电台闭环。  
6. **音效接入**（掌声、投信等 2–3 个）— 提升沉浸感。  
7. **选题 3D/翻牌 + 投信动画**（Lottie 或 CSS）— 视觉升级。  
8. **高级话题解锁**（部分话题花币）— 训练营与硬币联动。  
9. **冷场/救场彩蛋 + 徽章** — 玩法扩展，可放在更后。
